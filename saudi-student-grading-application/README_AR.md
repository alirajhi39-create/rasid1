# رَصْد — منظومة إدارة ورصد درجات الطلاب (متوافقة مع لائحة تقويم الطالب ونظام نور)

تطبيق ويب عربي كامل (RTL) لإدارة الطلاب والفصول والمواد ورصد الدرجات في التعليم العام السعودي،
مع كشوف طباعة رسمية بترويسة وزارة التعليم وتصدير Excel مطابق لقوالب نظام نور.

> ملاحظة: التلميحات الخاصة بكلمات المرور غير موجودة في الواجهة إطلاقاً — كل معلم يسجّل بحسابه الخاص.

## المزايا الرئيسية

- **تعدد المعلمين (multi-tenant):** كل معلم ينشئ حسابه من `/register`، ويحصل على فضاء معزول بالكامل
  (فصوله، طلابه، مواده، درجاته، بيانات مدرسته ومديرها) — معزول بقيد `teacher_id` على مستوى قاعدة البيانات.
- **ربط المادة بالصف:** كل مادة تُربط بالصفوف التي تُدرَّس فيها (شرائح تفعيل لكل صف من صفحة «المواد والتوزيع») —
  لا تظهر المادة نهائياً في الرصد ولا في التقارير ولا في التصدير إلا في الصفوف المرتبطة بها.
- **فصلان دراسيان فقط وفترتان لكل فصل:** العام = الفصل الأول + الفصل الثاني، وكل فصل يبدأ بفترتين (الأولى/الثانية)،
  ولكل تركيبة (فصل × فترة) رصد مستقل بتنقّل مبدّلات علوية وتنقّل بالأسهم وEnter.
- **مجموع الفترتين، مجموع الفصلين والمتوسطات:** تبويب «ملخص الفصلين والعام» في التقارير — الفترات الأربع،
  مجموع كل فصل (200) ومتوسط الفترتين (100)، ثم محصلة العام: مجموع الفصلين (400)، متوسط الفصلين (200)،
  المتوسط العام (100)، النسبة والتقدير — بترويسة رسمية جاهزة للطباعة.
- **رصد سريع بتنقّل لوحة المفاتيح** (الأسهم + Enter + Tab) مع **حفظ تلقائي سحابي** ومؤشر حالة لحظي.
- **توزيع درجات مرن لكل مادة:** فتح/إغلاق أي خانة، خانات أعمال السنة (60) والاختبار النهائي (40)
  أو خانات مخصصة، عظمى مستقلة لكل خانة، وحساب تلقائي للمجموع والنسبة والتقدير (ممتاز/جيد جداً/جيد/مقبول/ضعيف).
- **استيراد جماعي للطلاب** من Excel/CSV أو باللصق من كشوف نظام نور مع اكتشاف الأعمدة تلقائياً.
- **تقارير رسمية:** كشف رصد الفصل، إشعار فردي لكل طالب (صفحة لكل إشعار)، تحليل أداء الفصل، وملخص العام —
  كلها بشعار وزارة التعليم الرسمي وتوقيع معلم المادة ومدير المدرسة، وجاهزة للطباعة أو الحفظ PDF.
- **تصدير Excel لنور** بترويسة رسمية RTL بنفس ترتيب أعمدة قالب الاستيراد.
- **أمان حقيقي:** كلمات المرور مشفّرة بـ scrypt، جلسة JWT (HS256) في httpOnly cookie صالحة 7 أيام.

## التقنيات

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Drizzle ORM · PostgreSQL
(توافق تلقائي مع Neon عبر SSL تلقائي عند اكتشاف `sslmode=require` أو نطاق `neon.tech`) · SheetJS (xlsx) · lucide-react

## النشر على Vercel + Neon (5 دقائق)

1. ارفع المشروع على مستودع GitHub ثم **Import Project** في Vercel.
2. من لوحة Vercel: **Storage → Create Database → Neon (Postgres)** ثم **Connect to Project** —
   ينشئ Vercel تلقائياً متغيّر `DATABASE_URL` بالصيغة `postgresql://…?sslmode=require`.
3. (اختياري) أضف متغيّر `AUTH_SECRET` بقيمة عشوائية طويلة لتوقيع جلسات JWT.
4. انشر (Deploy). **لا حاجة لأي أوامر SQL يدوية:** عند أول زيارة للموقع (تسجيل دخول أو التسجيل أو `/api/init-db`)
   تُنشأ الجداول تلقائياً ويُهجَّر `teacher_id` بأمان ولا تُمس أي بيانات.
5. أول حساب (المالك التاريخي للبيانات التجريبية) يُنشأ فقط عند قاعدة فارغة تماماً؛
   أي معلم جديد يسجّل من «إنشاء حساب معلم» ويحصل على فضاء نظيف بمواد جاهزة وتوزيع لائحي.

## الحساب التجريبي المبدئي (ولّده النظام أول مرة فقط)

عند أول تشغيل على قاعدة فارغة يُنشأ حساب `teacher` — غيّر كلمة مروره فوراً من «الإعدادات ← كلمة مرور حسابك».
باقي المعلمين ينشئون حساباتهم بأنفسهم من `/register`، ولا تظهر أي تلميحات في الواجهة.

## ملاحظات فنية

- العزل بين المعلمين مفروض في كل استعلام (`teacher_id` على الفصول والمواد، واشتقاق الطلاب عبر الفصل والخانات عبر المادة).
- `CREATE TABLE IF NOT EXISTS` + `ALTER TABLE … ADD COLUMN IF NOT EXISTS` — التهيئة قابلة للتكرار قسراً.
- الـ Backfill المُدرج للبيانات يتم **مرة واحدة في العمر** عبر جدول `rased_meta` — لا يمس روابط فكّها المعلم إطلاقاً.
- `@media print` يخفي الواجهة بالكامل ويُخرج الكشف فقط (A4) — جرّبه من «التقارير ← طباعة / PDF».
- متوافق مع نور: أعمدة `رقم السجل المدني | اسم الطالب | …خانات الدرجات (العظمى) | المجموع | النسبة | التقدير`.
